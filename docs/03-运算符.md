# Java 运算符

> 大部分运算符与 PHP 相同，重点关注差异部分！

---

## 一、与 PHP 相同的运算符

| 类型 | 运算符 | 示例 |
|------|--------|------|
| 算术 | `+` `-` `*` `/` `%` | `a + b`、`10 % 3` |
| 赋值 | `=` `+=` `-=` `*=` `/=` `%=` | `a += 1` |
| 比较（基本类型） | `>` `<` `>=` `<=` `==` `!=` | `a > b` |
| 逻辑 | `&&` `\|\|` `!` | `a > 0 && b > 0` |
| 三元 | `条件 ? 值1 : 值2` | `a > b ? a : b` |
| 自增自减 | `++` `--` | `i++`、`--i` |

---

## 二、与 PHP 不同的地方（重点）

### 1. 字符串拼接：`+` 而不是 `.`

```php
// PHP 用 . 拼接字符串
$name = "Tom";
echo "Hello " . $name;  // Hello Tom
```

```java
// Java 用 + 拼接字符串
String name = "Tom";
System.out.println("Hello " + name);  // Hello Tom
```

---

### 2. 字符串比较：`equals()` 而不是 `==`

```php
// PHP 中 == 比较字符串值没问题
$a = "hello";
$b = "hello";
var_dump($a == $b);  // true
```

```java
// Java 中 == 比较的是内存地址，不是值！
String a = new String("hello");
String b = new String("hello");

System.out.println(a == b);       // false ❌（地址不同）
System.out.println(a.equals(b));  // true  ✅（值相同，推荐）
```

> ⚠️ **这是 Java 最容易踩的坑之一！** 字符串比较永远用 `equals()`，不用 `==`。

---

### 3. 整数除法自动截断小数

```php
// PHP：整数相除结果是浮点数
var_dump(7 / 2);   // float(3.5)
```

```java
// Java：两个 int 相除，小数部分直接丢弃
System.out.println(7 / 2);    // 3（不是 3.5！）
System.out.println(7.0 / 2);  // 3.5（有一个是小数就正常）
System.out.println((double) 7 / 2);  // 3.5（强制转换）
```

---

### 4. 没有 `===` 全等运算符

```php
// PHP 有 === 严格比较类型+值
var_dump(1 === "1");  // false
var_dump(1 == "1");   // true（弱类型自动转换）
```

```java
// Java 不需要 ===，因为本身就是强类型
// int 和 String 根本无法比较，编译直接报错
int a = 1;
String b = "1";
// a == b  → ❌ 编译报错，类型不匹配
```

## 三、运算符示例代码

```java
public class Demo {
    public static void main(String[] args) {
        // 算术运算符
        int a = 10, b = 3;
        System.out.println(a + b);   // 13
        System.out.println(a - b);   // 7
        System.out.println(a * b);   // 30
        System.out.println(a / b);   // 3（注意：整数除法截断）
        System.out.println(a % b);   // 1（取余）

        // 比较运算符
        System.out.println(a > b);   // true
        System.out.println(a == b);  // false

        // 逻辑运算符
        System.out.println(a > 5 && b > 5);  // false
        System.out.println(a > 5 || b > 5);  // true
        System.out.println(!(a > 5));         // false

        // 三元运算符
        int max = a > b ? a : b;
        System.out.println(max);  // 10

        // 自增
        int c = 5;
        System.out.println(c++);  // 5（先用后加）
        System.out.println(c);    // 6
        System.out.println(++c);  // 7（先加后用）
    }
}
```

## 四、总结

| 知识点 | PHP | Java |
|--------|-----|------|
| 字符串拼接 | `.` | `+` |
| 字符串比较 | `==` | `equals()` |
| 整数除法 | 结果为浮点数 | 自动截断小数 |
| 全等运算 | `===` | 不需要（强类型） |
| 其他运算符 | 与 Java 相同 | 与 PHP 相同 |

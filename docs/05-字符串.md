# Java 字符串（String）

> 在 Java 中，字符串 `String` 是**引用类型（对象）**，不是基本数据类型。

---

## 一、基础定义与引号规则

- **双引号 `""`**：专属 `String`（字符串，可以放多个字符）。
- **单引号 `''`**：专属 `char`（单个字符，比如 `'A'`，写 `'AB'` 会报错）。

```java
String s1 = "Hello";  // ✅ 正确
char c = 'A';         // ✅ 正确
// String s2 = 'Hello';  ❌ 编译报错！Java 不支持单引号表示字符串
```

---

## 二、核心机制：常量池与比较陷阱（⭐️ 必考重点）

### 1. `==` 与 `.equals()` 的区别
- **`==`**：比较两个变量保存的**内存地址**（门牌号）。
- **`.equals()`**：走进房间，比较里面实际的**文本内容**。

### 2. 为什么会有这两种不同的结果？

```java
// 情况一：常量池复用（返回 true）
String str1 = "abc";
String str2 = "abc";
System.out.println(str1 == str2);      // true（地址相同）
System.out.println(str1.equals(str2)); // true（内容相同）

// 情况二：new 强制新建堆对象（返回 false）
String a = new String("abc");
String b = new String("abc");
System.out.println(a == b);      // false（地址不同，两个独立对象）
System.out.println(a.equals(b)); // true（内容相同）
```

### 3. 底层图解与原理解释

```text
【直接双引号定义】（常量池复用）
str1 ----\
          ---> [ 常量池 "abc" (地址: 0x100) ]
str2 ----/
(str1 == str2 为 true，因为指向同一个地址)

【new String() 定义】（每次在堆内存开辟新房间）
a -------> [ 堆内存 A: "abc" (地址: 0x201) ]
b -------> [ 堆内存 B: "abc" (地址: 0x202) ]
(a == b 为 false，因为门牌号 0x201 != 0x202)
```

> ⚠️ **黄金避坑法则**：  
> 在实际业务开发中，字符串来源复杂（用户输入、数据库、接口），**判断字符串内容相等永远只用 `.equals()`，绝不用 `==`！**

## 三、`String[]` 数组定义语法

在 Java 中，中括号 **`[]` 代表数组**。

```java
String[] words = "Java is Great".split(" ");
```

- **`String`**：说明数组内部每个元素必须是字符串。
- **`[]`**：表示这是一个装多个同类型数据的数组容器。
- **`words`**：数组变量名。

### 访问与获取长度对比

```java
String[] arr = {"Java", "PHP", "Go"};

// 1. 取值（和 PHP 一样）
System.out.println(arr[0]); // Java

// 2. 获取长度（PHP 用 count($arr)，Java 用 .length）
System.out.println(arr.length); // 3
```

## 四、Java vs PHP 常用字符串方法对照表

Java 是纯面向对象，字符串操作是通过**调用对象自身的方法**（`s.xxx()`），而不是 PHP 的全局函数。

| 功能 | PHP 写法 | Java 写法 | 关键区别与注意点 |
| :--- | :--- | :--- | :--- |
| **获取长度** | `strlen($s)` | `s.length()` | Java 是方法，记得带括号 `()` |
| **字符串拼接** | `$a . $b` | `a + b` | Java 用 `+` 号拼接 |
| **比较内容** | `$a == $b` | `s1.equals(s2)` | **严禁用 `==` 比较 Java 字符串内容** |
| **转大/小写** | `strtoupper($s)` | `s.toUpperCase()` / `s.toLowerCase()` | |
| **查找位置** | `strpos($s, "a")` | `s.indexOf("a")` | 找不到时：Java 返回 `-1`，PHP 返回 `false` |
| **截取子串** | `substr($s, 0, 5)` | `s.substring(0, 5)` | ⚠️ **大坑**：Java 第二个参数是**结束索引(不含)**，PHP 是**长度** |
| **字符串替换** | `str_replace("a","b",$s)` | `s.replace("a", "b")` | |
| **拆分成数组** | `explode(",", $s)` | `s.split(",")` | Java 返回强类型数组 `String[]` |
| **去首尾空格** | `trim($s)` | `s.trim()` | |
| **判断包含** | `str_contains($s, "a")` | `s.contains("a")` | 返回 boolean（`true`/`false`） |

## 五、经典代码实战示例

```java
public class StringDemo {
    public static void main(String[] args) {
        String text = " Java is Awesome! ";

        // 1. 去除首尾空格
        String cleanText = text.trim();
        System.out.println("去除空格后: [" + cleanText + "]"); // [Java is Awesome!]

        // 2. 获取长度
        System.out.println("长度: " + cleanText.length()); // 16

        // 3. 截取字符串（从索引 0 开始，到索引 4 之前）
        String sub = cleanText.substring(0, 4);
        System.out.println("截取结果: " + sub); // Java

        // 4. 字符串替换
        String replaced = cleanText.replace("Awesome", "Great");
        System.out.println("替换后: " + replaced); // Java is Great!

        // 5. 拆分成字符串数组并遍历
        String[] words = cleanText.split(" ");
        System.out.println("单词总数: " + words.length); // 3
        System.out.println("第一个单词: " + words[0]);   // Java
    }
}
```

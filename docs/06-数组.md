# Java 数组（Array）

> 对比 PHP：PHP 数组是动态、混合类型、支持字符串键的“瑞士军刀”；而 Java 原生数组是**定长、强类型、纯数字下标**的纯粹容器。

---

## 一、Java 数组的核心特征（三大铁律）

| 特性 | PHP 数组 | Java 数组 |
| :--- | :--- | :--- |
| **元素类型** | 任意混装（`[1, "hello", true]`） | **单一类型**（`int[]` 只能存整数） |
| **数组长度** | **动态变长**（随时 `$arr[] = 4`） | **固定死**（一旦创建，长度不可变） |
| **下标/键名** | 支持字符串键（`$arr['name']` 关联数组） | **只有数字下标**（`0, 1, 2...`） |
| **数组越界** | 报 Notice，返回 `null` | **直接崩溃抛异常**（`ArrayIndexOutOfBoundsException`） |

---

## 二、数组的 2 种定义与初始化方式

### 1. 静态初始化（一开始就知道具体数据）
```java
// 简写（最常用）
int[] nums = {5, 2, 8, 1};
String[] names = {"Tom", "Jerry", "Spike"};

// 完整写法（等价）
int[] nums = new int[]{5, 2, 8, 1};
```

### 2. 动态初始化（只知道长度，先占坑位，后续填值）
```java
// 声明一个长度为 3 的 int 数组，内部元素默认填充初始值 0
int[] arr = new int[3];

arr[0] = 10;
arr[1] = 20;
arr[2] = 30;
// arr[3] = 40; ❌ 越界异常！因为长度只有 3（有效索引为 0, 1, 2）
```

> **默认初始值规则**：
> - 整数类型（`byte`, `short`, `int`, `long`）：`0`
> - 浮点类型（`float`, `double`）：`0.0`
> - 布尔类型（`boolean`）：`false`
> - 引用类型（`String`, 对象等）：`null`

## 三、数组的两种遍历方式

### 1. 普通 for 循环（按索引遍历，和 PHP 一样）
```java
int[] nums = {10, 20, 30};

for (int i = 0; i < nums.length; i++) {
    System.out.println("索引 " + i + " 的值: " + nums[i]);
}
```

### 2. 增强 for 循环（类似 PHP 的 foreach）

```java
// 语法：for (元素类型 临时变量名 : 数组名)
for (int n : nums) {
    System.out.println(n);
}
```

#### 💡 PHP vs Java 增强遍历对比：
```php
// PHP：大数组在前，临时变量在后
foreach ($nums as $n) {
    echo $n;
}
```
```java
// Java：带类型的临时变量在前，冒号表示“来自”，大数组在后
for (int n : nums) {
    System.out.println(n);
}
```

## 四、数组打印与操作（`java.util.Arrays` 工具类）

在 Java 中，直接 `System.out.println(arr)` 只会打印出数组的**内存地址标识**（如 `[I@6acbcfc0`）。必须使用工具类：

### 1. 打印数组内容（类似 PHP 的 `print_r` / `var_dump`）
- **一维数组**：`Arrays.toString(arr)`
- **多维数组**：`Arrays.deepToString(matrix)`

```java
import java.util.Arrays;

int[] nums = {5, 2, 8, 1};
System.out.println(Arrays.toString(nums)); // 输出: [5, 2, 8, 1]

int[][] matrix = {{1, 2}, {3, 4}};
System.out.println(Arrays.deepToString(matrix)); // 输出: [[1, 2], [3, 4]]
```

### 2. 数组排序与内存地址变化
```java
int[] nums = {5, 2, 8, 1};

// 原地排序（升序）
Arrays.sort(nums);

System.out.println(Arrays.toString(nums)); // 输出: [1, 2, 5, 8]
```
> ⚠️ **关于内存地址**：  
> `Arrays.sort(nums)` 是**原地修改**，只调整数组内部元素的顺序，**数组本身的内存地址不会发生任何改变**！

## 五、PHP vs Java 常用数组操作对照表

| 操作 | PHP 写法 | Java 标准写法 |
| :--- | :--- | :--- |
| **获取数组长度** | `count($arr)` | `arr.length`（属性，不带括号） |
| **打印一维数组** | `print_r($arr)` / `var_dump($arr)` | `System.out.println(Arrays.toString(arr));` |
| **打印多维数组** | `print_r($arr)` | `System.out.println(Arrays.deepToString(arr));` |
| **数组升序排序** | `sort($arr)` | `Arrays.sort(arr);`（原地修改，地址不变） |
| **遍历数组** | `foreach ($arr as $item)` | `for (int item : arr)` |

# Java 基本数据类型

> 对比 PHP：PHP 是弱类型，变量无需声明类型；Java 是**强类型**，必须显式指定类型。

---

## 一、变量定义语法

```java
// 语法：数据类型  变量名  =  初始值;
int a = 10;
```

对比 PHP：
```php
// PHP 无需声明类型
$a = 10;
```

---

## 二、8种基本数据类型

### 整数类型

| 类型 | 大小 | 取值范围 | 示例 |
|------|------|---------|------|
| `byte` | 1 字节 | -128 ~ 127 | `byte b = 100;` |
| `short` | 2 字节 | -32768 ~ 32767 | `short s = 1000;` |
| `int` | 4 字节 | 约 ±21亿 | `int i = 100;` |
| `long` | 8 字节 | 约 ±922亿亿 | `long l = 100L;` |

### 小数类型

| 类型 | 大小 | 精度 | 示例 |
|------|------|------|------|
| `float` | 4 字节 | 6~7 位有效数字 | `float f = 3.14F;` |
| `double` | 8 字节 | 15~16 位有效数字 | `double d = 3.14;` |

### 其他类型

| 类型 | 大小 | 说明 | 示例 |
|------|------|------|------|
| `char` | 2 字节 | 单个字符，用单引号 | `char c = 'A';` |
| `boolean` | 1 字节 | true / false | `boolean flag = true;` |

## 三、类型后缀（重要）

Java 中数字字面量有默认类型：
- **整数**默认是 `int`
- **小数**默认是 `double`

| 后缀 | 类型 | 示例 |
|------|------|------|
| `F` 或 `f` | float | `3.14F` |
| `L` 或 `l` | long | `100L`（推荐大写） |

```java
float f = 3.14F;   // ✅ 必须加 F，否则 3.14 是 double 类型，报错
long  l = 100L;    // ✅ 数值超过 int 范围时必须加 L
```

---

## 四、默认类型总结

```
整数：100     → int（默认）
整数：100L    → long
小数：3.14    → double（默认）
小数：3.14F   → float
```

## 五、各类型取值范围（代码获取）

```java
System.out.println(Integer.MAX_VALUE);  // int 最大值：2147483647
System.out.println(Integer.MIN_VALUE);  // int 最小值：-2147483648
System.out.println(Long.MAX_VALUE);     // long 最大值：9223372036854775807
System.out.println(Float.MAX_VALUE);    // float 最大值
System.out.println(Double.MAX_VALUE);   // double 最大值
```

## 六、整数溢出

```java
int a = 2147483647;     // int 最大值
System.out.println(a + 1);  // 输出：-2147483648（溢出！绕回最小值）
```

> ⚠️ 超过范围不会报错，而是静默溢出，产生错误结果，需特别注意。

## 七、float/double 精度问题

```java
// ❌ 不能用于金融计算
double money = 0.1 + 0.2;
System.out.println(money);  // 输出：0.30000000000000004

// ✅ 金融计算用 BigDecimal
import java.math.BigDecimal;
BigDecimal m = new BigDecimal("0.1").add(new BigDecimal("0.2"));
System.out.println(m);  // 输出：0.3
```

## 八、变量定义的几种方式

```java
// 1. 定义并赋值（最常用）
int a = 10;

// 2. 先定义，后赋值
int b;
b = 20;

// 3. 一次定义多个同类型变量
int x = 1, y = 2, z = 3;
```

## 九、PHP vs Java 对比总结

| 概念 | PHP | Java |
|------|-----|------|
| 变量定义 | `$a = 10;` | `int a = 10;` |
| 整数默认类型 | int（自动） | `int`（需显式声明） |
| 小数默认类型 | float | `double` |
| 强制指定 float | 无需后缀 | 必须加 `F` |
| 大整数 | 自动处理 | 用 `long`，加 `L` |
| 类型转换 | 隐式自动 | 必须显式 `(float) 3.14` |

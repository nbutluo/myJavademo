# Java 类型转换

Java 是强类型语言，不同类型的数据需要转换才能互相赋值或运算。

---

## 一、自动类型转换（隐式转换）

**规则：小范围 → 大范围，Java 自动完成。**
就像把小杯子里的水倒入大杯子，绝对安全，不会溢出。

转换顺序链：
`byte → short → int → long → float → double`

```java
int a = 10;
double b = a;  // ✅ 自动转换，int → double
System.out.println(b);  // 输出：10.0
```

---

## 二、强制类型转换（显式转换）

**规则：大范围 → 小范围，必须手动强转。**
就像把大杯子的水强行倒入小杯子，**可能会溢出或丢失精度**。

语法：`目标类型 变量名 = (目标类型) 原变量;`

```java
double a = 3.99;
int b = (int) a;        // 强转，小数直接截断（不是四舍五入！）
System.out.println(b);  // 输出：3

long c = 1000L;
int d = (int) c;        // long → int
```

---

## 三、字符串与数字互转（⭐️ 核心重点）

> **超通俗记忆法：找“数学专家”办事！**
> 在 Java 里，`String` 只是普通的文本纸张；而 `Integer` 和 `Double` 等包装类是**数学专家**。
> **铁律：只要转换涉及到数字，永远找数字对应的“专家”！**

### 1. 文本 ➡️ 数字（请专家“解析”文本）
手里有张写着 `"123"` 的纸条，找 `Integer` 专家解析（`parse`）成整数（`Int`）：
```java
// “Integer 专家，请把这段文本解析 (parse) 成整数 (Int)。”
int a = Integer.parseInt("123");

// “Double 专家，请把这段文本解析 (parse) 成小数 (Double)。”
double b = Double.parseDouble("3.14");
```

### 2. 数字 ➡️ 文本（请专家把数字“写”成文本）
手里有真实的数字 `123`，找 `Integer` 专家把它转成文本（`toString`）：
```java
// “Integer 专家，请把数字转成字符串 (toString)。”
String s1 = Integer.toString(123);

// “Double 专家，请把数字转成字符串 (toString)。”
String s2 = Double.toString(3.14);
```

### 3. 偷懒写法（PHP 开发者最爱）
直接加上空字符串 `""`，利用字符串拼接特性瞬间变文本：
```java
String s3 = 123 + "";
```

## 四、复合示例拆解

遇到复杂的转换代码，**从里向外**一层层看：

```java
int d1 = (int) Double.parseDouble("3.45");
```
**拆解步骤：**
1. `Double.parseDouble("3.45")` → 专家出马，将文本变为数值 `3.45`（double）
2. `(int) 3.45` → 大杯倒小杯（强制转换），截断小数部分变成 `3`
3. `int d1 = 3;` → 最终赋值

---

## 五、PHP vs Java 总结

| 场景 | PHP | Java |
|------|-----|------|
| 文本转数字 | `(int)"123"` | 找专家：`Integer.parseInt("123")` |
| 数字转文本 | `(string)123` | 找专家：`Integer.toString(123)` |
| 混用报错 | 自动转换（`"123"+1`）| 严格报错，必须明确找专家转换 |
| 小数转整数 | `(int) 3.99` 结果 3 | `(int) 3.99` 结果也是 3（截断） |

# Java 类型转换

Java 是强类型语言，不同类型的数据需要转换才能互相赋值或运算。

---

## 一、自动类型转换（隐式转换）

**规则：小范围 → 大范围，Java 自动完成。**
就像把小杯子里的水倒入大杯子，绝对安全，不会溢出。

转换顺序链：
`byte → short → int → long → float → double`
*(注：`char` 也可以自动转换为 `int`)*

```java
int a = 10;
double b = a;  // ✅ 自动转换，int → double
System.out.println(b);  // 输出：10.0
```

---

## 二、强制类型转换（显式转换）

**规则：大范围 → 小范围，必须手动强转。**
就像把大杯子的水强行倒入小杯子，**可能会溢出或丢失精度**。

语法：`目标类型 变量名 = (目标类型) 原变量;`

```java
double a = 3.99;
int b = (int) a;        // 强转，小数直接截断（不是四舍五入！）
System.out.println(b);  // 输出：3

long c = 1000L;
int d = (int) c;        // long → int
System.out.println(d);  // 输出：1000
```

---

## 三、字符串与数字互转（高频操作）

### 1. 字符串 → 数字
```java
int a = Integer.parseInt("123");
double b = Double.parseDouble("3.14");
long c = Long.parseLong("999999");
```
> ⚠️ **注意**：如果字符串里包含字母（如 "123a"），转换时会报错 `NumberFormatException`。

### 2. 数字 → 字符串
```java
String s1 = String.valueOf(100);     // 推荐写法
String s2 = Integer.toString(100);   // 推荐写法
String s3 = 100 + "";               // 简单写法，底层效率略低
```

## 四、复合示例拆解

遇到复杂的转换代码，**从里向外**一层层看：

```java
// 目标：将字符串 "3.45" 转为整数
int d1 = (int) Double.parseDouble("3.45");
```
**拆解执行步骤：**
1. `Double.parseDouble("3.45")` → 将字符串变为 `3.45`（double）
2. `(int) 3.45` → 将 double 强转为 int，截断小数部分，变成 `3`
3. `int d1 = 3;` → 最终赋值

## 五、PHP vs Java 总结

| 场景 | PHP | Java |
|------|-----|------|
| 数字与字符串混用 | 自动隐式转换，极其灵活 | 严格报错，必须明确转换 |
| 字符串转数字 | `(int)"123"` 或自动转换 | 必须用 `Integer.parseInt()` 等方法 |
| 数字转字符串 | `(string)123` 或自动转换 | `String.valueOf(num)` 或拼接 `""` |
| 小数转整数 | `(int) 3.99` 结果是 3 | `(int) 3.99` 结果也是 3（直接截断） |

# Java 包装类型 vs 基本类型

---

## 一、两大类型体系

```
Java 类型
├── 基本类型（8种）→ 直接存值，存在栈上
│   ├── int、long、short、byte
│   ├── float、double
│   ├── char
│   └── boolean
│
└── 引用类型（对象）→ 存的是内存地址
    ├── 包装类：Integer、Long、Float、Double、Character、Boolean...
    ├── String
    ├── 数组
    └── 自定义类（class）
```

---

## 二、基本类型 vs 包装类对照表

| 基本类型 | 包装类 |
|---------|--------|
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |
| `byte` | `Byte` |
| `short` | `Short` |

> 规律：基本都是首字母大写；`int → Integer`、`char → Character` 是特殊的。

---

## 三、主要区别

| 对比项 | `int`（基本类型） | `Integer`（包装类） |
|--------|-----------------|-------------------|
| 类型分类 | 基本数据类型 | 对象（引用类型） |
| 定义方式 | `int i = 1;` | `Integer i = 1;` |
| 能否为 null | ❌ 不能 | ✅ 能 |
| 内存位置 | 栈（直接存值） | 堆（存对象地址） |
| 有无方法 | ❌ 没有 | ✅ 有很多工具方法 |
| 性能 | 更快 | 稍慢（对象开销） |

---

## 四、为什么需要包装类？

### 1. 集合只能存对象，不能存基本类型

```java
List<int> list = new ArrayList<>();      // ❌ 报错
List<Integer> list = new ArrayList<>();  // ✅ 正确
```

### 2. 可以赋值 null

```java
int a = null;       // ❌ 报错，基本类型不能为 null
Integer b = null;   // ✅ 正确（表示"无值"）
```

### 3. 包装类有实用的工具方法

```java
// 字符串转数字（非常常用！）
int num = Integer.parseInt("123");

// 获取最大最小值
System.out.println(Integer.MAX_VALUE);  // 2147483647
System.out.println(Integer.MIN_VALUE);  // -2147483648

// 数字转字符串
String s = Integer.toString(100);       // "100"
```

---

## 五、定义方式（推荐写法）

```java
// ❌ 旧写法（Java 9 已废弃）
Integer i1 = new Integer(1);

// ✅ 推荐：直接赋值（自动装箱）
Integer i2 = 1;

// ✅ 推荐：valueOf()
Integer i3 = Integer.valueOf(1);
```

---

## 六、自动装箱 / 拆箱

Java 会自动在基本类型和包装类之间转换，无需手动处理：

```java
// 自动装箱：int → Integer
Integer a = 1;          // 等价于 Integer.valueOf(1)

// 自动拆箱：Integer → int
int b = new Integer(5); // 等价于 new Integer(5).intValue()

// 混合运算也没问题
Integer x = 10;
int y = x + 5;  // 自动拆箱后运算，结果为 15
```

---

## 七、对比 PHP

```php
// PHP 没有基本类型和对象类型之分，一切动态
$i = 1;
$i = null;  // 随时可以赋 null，没有限制
```

Java 之所以区分，是为了性能（基本类型更快）和功能（包装类能用在集合、可为 null）。

---

## 八、总结一句话

> `int` 是简单数字，快但功能少；`Integer` 是把数字包装成对象，能调方法、能赋 null、能放进集合。
